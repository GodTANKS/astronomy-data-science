## 콘텐츠 구성

### 외계행성계 탐사
Google Colab에서 실제 외계행성 카탈로그를 분석합니다.

### 구상성단 분포
구상성단의 2D·3D 공간 분포로 우리은하 중심을 탐구합니다.

### 태양계 천체 역학적 분류
궤도요소와 카탈로그 데이터를 이용해 태양계 천체의 역학적 특성을 분석합니다.

### 딥러닝 기반 은하 분류
은하 이미지를 이용해 CNN 학습과 성능 평가, 오분류 해석을 경험합니다.

### 외부고리 은하 영상 분석
SDSS FITS 데이터를 이용해 실제 천문 영상 처리·분석 절차를 수행합니다.
