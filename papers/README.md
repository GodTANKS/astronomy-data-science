# Paper Library

1. highschool-astronomy-coding.pdf

   - 조훈 · 손정주
   - 외계행성계 탐사 / 구상성단 분포 콘텐츠

   - 조훈 · 손정주

3. galaxy-classification-deep-learning.pdf  
   - 딥러닝 기반 은하 분류 교육 콘텐츠 개발
   - 조훈 · 손정주

4. outer-ring-galaxy.pdf  
   - 외부고리 은하 영상 분석을 위한 파이썬 기반 알고리즘 개발
