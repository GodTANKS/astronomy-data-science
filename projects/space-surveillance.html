🛰️ SGP4 모델과 AI 모델을 활용한 STSE 우주감시 웹 콘텐츠 개발

조훈 · 손정주

SGP4AI 보정 모델TLESTSE논문 제출 중

연구 개요

2022 개정 고등학교 「행성우주과학」의 우주 위험 감시 맥락에서 실제 TLE 자료를 수집·전처리하고, SGP4 물리 모델과 AI 보정 모델의 결과를 비교하여 우주물체의 근접 위험과 예측 불확실성을 탐구하도록 구성한 웹 기반 교육 콘텐츠입니다.

탐구 구조

  • 1. 문제 정의
  • 2. 데이터 수집 및 전처리
  • 3. 데이터 탐색 및 시각화
  • 4. SGP4 물리 모델 분석
  • 5. AI 보정 모델 분석
  • 6. 일반화 및 결론
논문 제출 중 · 코드와 논문 원문 비공개
현재 연구는 논문 제출 절차가 진행 중이므로 소스 코드, 활동지 원본, 세부 구현 자료와 논문 PDF는 공개하지 않습니다. 연구 아이디어·코드·문서·시각 자료의 무단 복제, 재배포, 출처 없는 학술적 전용을 금하며, 비공개 자료의 이용은 저자의 사전 동의가 필요합니다.

공개 기록

이 페이지는 연구 진행 사실과 공개 시점을 기록하기 위해 2026-09-25 GitHub Pages에 게시되었습니다. 이 공개 기록은 연구의 공개 시점을 확인하는 자료가 될 수 있지만, 특허권이나 학술적 우선권을 자동으로 부여하는 법적 등록 절차를 의미하지는 않습니다.
